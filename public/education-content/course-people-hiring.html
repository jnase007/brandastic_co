Build a Hiring Process

Hiring is a pipeline with stages — same seriousness as sales.

Source: Hiring process

Stages (from file)

  1. Intake meeting with hiring manager
  2. Post on platforms / advertise
  3. Source / outbound
  4. Filter candidates
  5. Screen
  6. Psychological assessment
  7. WHO interview
  8. Technical assessment
  9. Presentation / later stages

Also includes function-specific process (e.g. Paid Media process tab).

Brandastic

  • No hire without scorecard (see AE scorecard page)
  • Technical mock before offer on specialist roles
  • Justin final values gate on key seats
